# Deco browser studio

FastAPI serves `editor.html` at `/editor` and `static/` at `/static`. No Node build is required. The page implements local project browsing, room import/generation, live Viser editing, camera keyframes, and MP4 playback/downloads. `static/studio.js` adds the demo and project library; `static/studio.css` supplies the responsive presentation design.

Run `./scripts/demo.sh` from the repository root. See [the presentation guide](../../docs/demo-walkthrough.md).
